## 2. 遊びの全体像（いまのきまり）

正本は、ゲームの「あそびかた」（`#a2RulesOv`）。ここでは要点だけ。

**戦闘**
- 坩堝は5列×5段。札を使うと、その元素の欠片が選んだ列に落ちて積もる。1手番に3枚（手数）。
- 落ちた・動いた・変わった欠片は、触れている欠片と反応する（下・左・右・上の順）。
  - 同じ元素・同じ段階は**合成**（一段上へ）。低いほうに残り、横どうしなら動いた側へ相手を引き寄せる。
  - 反対の元素（火⇔水・風⇔土）・同じ段階は**対消滅**。調律の光が顕現を打つ（雫3・輝石8・光核20・真理50）。
- 消えた跡に上が落ちて**連鎖**する。k回目の反応は×k。
- 札で落とした欠片だけは、反応できる相手が2つ以上あれば**相手を選べる**（列の数字に「⇆」）。
- 合成するたびに**〈溜め〉**が貯まる（できた段階ぶん。坩堝の中の合成だけ）。次の対消滅の基本の調律力に足され、連鎖の倍率もかかって使い切られる。
- 坩堝はあなたの楽器：合成はいつもあなたのもの、対消滅はいつも顕現を打つ。

**混沌（敵）**
- 顕現は予告どおりに混沌を降らせる。**反応しない列を選んで**降る（逃げ場がなければ反応する）。
- **あなたの手番の終わり**に、坩堝に残した混沌が段階の数だけ器を**蝕む**（そのあとで慈雨が回復）。敵の番に、列からあふれても器が削れる。
- 予告には、撃（器を直接削る）と染（いちばん大きな自分の欠片を混沌にする。同じ大きさなら左の列から。混沌が染みこむ演出と効果音、染められた欠片には「染」の印。光・闇で取り返すと印は消える）もある。第三幕の顕現の一部（光喰い・双子の影・混沌そのもの）は、予告の「乱4」で混沌の真理を降らせる。乱れ（体力）が半分を切ると「荒ぶる」顕現もいる（予告や降らせ方が変わる）。

**札の種類**（札ごとに動かすものが一つずつ：光＝段階を上げる／闇＝段階を下げる／天秤＝場所／無垢＝台）
- **元素の札**（雫・輝石・光核）。**札は光核まで**。真理は坩堝の中でだけ生まれる（光核どうしの合成か、光核に光）。
- **光〈昇華〉**：坩堝の欠片の段階を+1（無垢なら浄化）。
- **闇〈沈降〉**：段階を−1。**雫なら消えて上が落ちる**（崩して落とす）。下がった欠片はすぐ反応する。
- 光・闇で変えた欠片は**あなたの欠片になる**（混沌に使えば「調律した」。混沌の雫を沈降すれば消える）。
- **無垢の札**（雫だけ・1拍）：列を押すと〈足場〉（中身のない殻）を置く。何とも反応せず、上に積める。手数は使わず、1手番に1枚。周り8マスの対消滅の衝撃で割れ、上の欠片が落ちる。顕現の無垢も同じ中身のない殻（1拍）。
- **天秤〈入れ替え〉**（札は一種類・**第二幕から**並ぶ。第二幕のはじめの報酬で必ず出会う）：坩堝の2つの欠片の場所を入れ替える（手数1）。1つめを押すと相手が数字つきで光る。届く範囲は音叉で育つ：始まり＝隣どうし／〈兆しの音叉〉で同じ行・列／〈変革の音叉〉でどこでも（絵・名前も変わる。絵は角をとった正方形）。
- **〈残す〉**：手札のすぐ左の置き場。置いた札は次の手番に持ち越す（音叉で最大3枚）。札は**ドラッグ**でも動かせる（〈残す〉へ・手札へ・手札の札の上へ・坩堝の列や光る欠片へ）。

**真理**
- 坩堝にある自分の真理の数だけ力が重なる（上限なし）：烈火 +0.5倍/つ・慈雨 器+3/つ・疾風 手札+1/つ・不動 手数+1/つ。
- **真理解放**（真理どうしの対消滅）で、**次の敵の番の予告を封じる**（降らない・撃たない・染めない。残した混沌の蝕みは、手番の終わりにいつもどおり起きる。予告に「封」）。

**音叉と台座**
- 音叉にはコスト（1〜3）があり、**台座**（第一幕3・第二幕6・第三幕9）に収まるぶんだけ付けられる。付けた音叉だけが鳴る。入らない音叉は鞄へ（上の欄の「鞄」の後ろに点線の枠で並ぶ）。幕が変わって台座が広がると、鞄の音叉を手に入れた順に、入るだけ自動で付ける。
- 音叉を持っていれば、戦闘に入る前に**戦いの前の画面**（`R.phase = 'prep'`）が出る。顕現の乱れ・降らせ方（荒ぶったあとも）・降らせる元素と最大の段階・仕掛けが少しわかり、音叉を付け外しできる。混沌そのものは「？？？」。
- 育つ音叉（掌→双掌・兆し→変革・余韻→長き余韻）は、前の段を同じ台座で上書きする。
- 第一幕の主で〈掌の音叉〉、第二幕の主で〈双掌の音叉〉を必ず授かる（手札の中で、同じ札2枚の錬成と光の昇華。手数を使わない・光核まで・その戦闘だけ。〈溜め〉は溜まらない）。

**旅**
- 三幕、分かれ道の地図。戦・鋭（精鋭）・泉（休む／錬成（光核まで）／手放す）・市・謎（出来事6種）・主（幕の主）。
- 敵は21体（各幕：戦4・精鋭2・主1）＋練習の影。
- 報酬：勝つたびに札を1枚選ぶ。精鋭と主からは音叉も。主の報酬の札は一段上。第一幕の精鋭の報酬の元素の札は輝石。

### 坩堝のきまり `A2E`
画面に触れない純粋な関数。予告・予測・本番・ボットで同じ計算を使う。

| 関数 | 役目 |
|---|---|
| `rk(a, b)` | 2つの欠片の反応（merge / anni / null） |
| `resolve(S, actives, X)` | 反応を解いて連鎖させる（対消滅の衝撃で足場・無垢・殻が割れる） |
| `drop(S, c, f, X, hint)` | 列に落とす（`hint` は選んだ相手のます目）。足場もこれで置く |
| `apply(S, id, kind, X)` | 光〈昇華〉・闇〈沈降〉（変えた欠片はあなたのものに。雫の沈降は消える）。`shell1`/`shell2`（〈包む〉）の作りは残っているが、画面からは使わない |
| `swap(S, a, b, t, X)` / `swapPartners` / `swapReach` / `canSwapAny` | 天秤の入れ替え（t は段階：1 隣・2 行列・3 どこでも） |
| `partners(S, c, f, H)` | 落ちる先で反応できる相手 |
| `chooseCol(...)` | 混沌の狙い（性格：bury / tall / even / heavy） |
| `bite(S, X)` | 蝕み（あなたの手番の終わりに呼ぶ） |
| `enemyTurn(S, intent, X)` | 敵の番（降らす・撃・染）。`X.noBite` がなければ蝕みも先に数える（予報・ボット用）。封じた番は `intent = []` |

- `X`（場の決まりごと）は `A2` の `ctx()` が作る。`calc`（調律力。音叉・真理・〈溜め〉）、`H`、`ward`、`chargeX`、`frames`。
- `frames` に場面を記録すると、`play()` がそれを順に見せる（land / merging / merge / anni / shock / fall / wake / over / bite / strike / taint / raise / sink / weigh / swap など）。

### 状態の形（そのまま JSON で保存）
- **冒険 `R`**（`localStorage` の `genso.a2.run`）：`act, hp, maxHp, echo, deck, relics（持っている音叉）, equip（台座に付けた音叉）, balMet（天秤に出会ったか）, map, pos, path, phase（map/prep/battle/reward/rest/shop/event/end/tutdone）, prep, battle, reward（gift＝主から授かった音叉）, rest, shop, event, end, stats`
- **戦闘 `B = R.battle`**：`key, kind, en{hp,max,step,ph}, S, draw, hand, disc, plays, turn, intents, keep, shellUsed（足場を置いた数）, hc（手札での錬成の回数）, buried（栞）, seal（次の番を封じる）, bell, st`
- **坩堝 `S`**：`{ cols: [[欠片…]×5], nid, salt, charge }`
- **欠片**：`{ id, k: 'el'|'pure', e, t, own: 'you'|'foe', sh?, dyed? }`（`sh` は足場・無垢の残りの拍、`dyed` は〈染〉で染められた印）
- **札**：`{ id, k: 'el'|'light'|'dark'|'pure'|'bal', e, t, tmp?（種の札）, forged?（手札で錬成した札） }`
- **ほかの保存**：`genso.a2.best`（記録）・`genso.a2.tutDone`（はじめの練習）・`genso.a2.shellTut`（無垢の練習を見た／とばした）・`genso.a2.balTut`（天秤の練習）
- 古い保存の読み替えは `show()` の中（天秤の段階つきの札・真理の札・無垢の輝石の札・台座のない保存）。

## 5. 検証のしかた

- 道具は `tools/alchemy2/`（使い方は `tools/alchemy2/README.md`）。どれも `index.html` から、きまりと敵の表をその場で読む（`lib.js`）。
- **画面の試験**（Playwright）：`node tools/alchemy2/test/<名前>.js`。どれも最後に `no errors`。全12本で、たとえば `tutorial.js`（はじめの練習を最後まで）・`shell-practice.js`（無垢〈足場〉の練習）・`full-run.js`（三幕を通しで。十数分かかる）。
- **ボット**：
  - `sim.js`：敵ごとの器の減り（1手番を読むボット）。
  - `sim-skill.js`：腕前（rule／chain／read）・幕・音叉の組み合わせごとの勝率と器の減り。`DECKADD` で光・闇・無垢・天秤を足すと、それぞれを使った回数と、その手で与えた傷の割合も出る。`A2SRC` で前の版の `index.html` を読めば前後を比べられる。`FOEX` で敵の表を一時的に書き換えて案を比べられる。
- **きまりを変えたら**：`tutorial.js` と `shell-practice.js` を必ず回す（筋書きの数字が変わっていないか）。強さに関わるなら `sim-skill.js` で前後を比べ、設計メモに表で残す。
- 戦闘の途中の場面を試すときは、`localStorage` の `genso.a2.run` に状態を書き込んでから「続きから」。**音叉は `relics` と `equip` の両方に入れる**（付けた音叉だけが鳴る）。音叉を持っていると、地図から戦闘へは戦いの前の画面（`#a2Fight`）を通る。
- チュートリアルと練習は、数字（乱れの減り方）を説明の文に書いている。きまりを変えたら、`TUTS` の文と練習の影の体力（`FOES.renshu` は57、練習は `startTutorial` の中で9）を合わせる。
- CSS の変数名は、ほかの部品と重ならないように `--a2…` を付ける（`@property` で型を登録すると、同じ名前の変数がすべてその型になる。v1.101.2 の不具合）。
- 1手番しか読まないボットには限界がある：手番をまたぐ仕込み（足場・〈残す〉・〈溜め〉・天秤の先読み）、先見の眼・書の栞・余韻は、ボットでは測れないか過小に出る。

**腕前ごとのボットの手応え**（設計メモ20・24・26・27節）
- 第一幕：きまりを知っているだけ（rule）で主まで勝てる。音叉が入るとかなり易しい。
- 第二幕：rule は主で3〜5割負ける。工夫する（chain）・読む（read）は勝てる。主（四季の巡り）が山場で、どの音叉を付けるかで手応えが変わる。
- 第三幕：rule は主に勝てない。chain は主1戦なら勝てるが、道中と合わせると泉がないと届かない。read は道中と主を合わせて勝てる。
- → 依頼主の理想「第一幕＝きまり／第二幕＝工夫／第三幕＝読む」に、おおむね沿っている（第一幕は甘め）。

## 7. 残っていること・確かめていないこと

**試遊で見てほしいこと（v1.95.0〜v1.101.2 の変更）**
- 〈染〉の演出（混沌がジワリと染みこむ・低い効果音・「染」の印）で、染められたことに気づけるか。効果音の重さ・長さはちょうどよいか。
- 手に入れた音叉が鞄に入ったとき（報酬の画面の言葉・上の欄の「鞄」と点線の枠）と、幕が変わって鞄の音叉が自動で付くことが、わかりやすいか。
- 蝕みが手番の終わりに来ること（蝕み → 慈雨 → 敵の番）と、予報が「手番の終わりに」「敵の番に」の二つに分かれたことが、わかりやすいか。
- 第一幕で、闇〈沈降〉と無垢〈足場〉を取りたくなるか。使い道が見えるか。
- 闇〈沈降〉で自分の雫を消して上を落とす手が、強すぎないか（ボットでは闇の手の傷は全体の5〜10%）。
- 天秤が第二幕から入って、加速が気持ちよく感じられるか。〈兆し〉〈変革〉に出会えるか。
- 〈足場〉の手応え（ボットはほとんど使わないので、人の感覚がたより）。

**調整の候補（依頼主と相談中）**
- 〈真理の灯〉〈火水〉は台座1にしては強め（様子を見ている）。
- 第一幕は音叉が入ると易しい（台座3でも、きまりを知っているだけの打ち方で主まで全勝）。主を強めるか、台座を2にするかは試遊の感覚で。
- 第三幕の主（混沌そのもの）の体力は、試遊の手応えを聞いてから。

**ルール・演出**
- 指でドラッグした直後（0.3秒以内）のタップが、自動の試験ではときどき効かない（ふつうのタップとドラッグは毎回通る）。実機で気になるか見る。
- 天秤の練習は隣どうしだけ。兆し・変革の使い方は教えていない（驚きのため）。
- 闇〈沈降〉の練習の段はない（はじめのチュートリアルで説明するだけ）。必要なら、無垢・天秤と同じく、はじめて報酬に並んだときの練習を作れる。
- はじめのチュートリアル（`TUTS.main`）の筋書きは、闇〈反転〉のころのまま闇を説明だけの段にしている。沈降を操作で教える段を足すかは未定。

**音叉の案**
- 〈導き〉（手番に1度、予告の混沌1つの降る列を決められる）は、案として話しただけ。

**量と扱い**
- 敵21体・出来事6種・音叉27種（報酬・市に出るのは24種）。長く遊ぶには増やしたい。
- 別ブランチ `claude/trusting-cerf-hkgqca`・`claude/vigilant-archimedes-xqxi4y` に main にないコミットがあるが、どちらも錬成の書２より前の古い作業（初期の版・もとの錬成の書の検証中の版）で、いまの main とは別の流れ。`claude/practical-franklin-at5jly` の中身は v1.93.0 で取り込み済み。

## 8. 作業の進め方（これまでの約束）

- 依頼主の試遊の報告（「〜が表示されていない気がする」など）は、まず仕組みを調べてブラウザで再現し、原因（不具合か、仕様のわかりにくさか）を説明してから、直し方を出す。
- 依頼主とのやりとりは日本語。「〜でしょうか」「どうですか」と意見を求められたら、まず意見を出す。数字で決めたいときは「ボットで比べてから」。案が複数あるときは、おすすめを一つ示す。
- **main へ上げるのは、依頼主が「メインに上げてください」と言ったときだけ**。それまでは作業ブランチにプッシュして、上げるかどうかを尋ねる。main が先に進んでいなければ、早送りで上げる。上げるときは、この引継書の「main はどこまでか」も合わせて直す。
- **別のセッションが同じ `index.html` の別のモード（サバイバルなど）を並行して main に上げることがある**。main に上げる前に `git fetch origin main` で確かめ、進んでいれば作業ブランチに main を取り込んで（衝突は錬成の書の部分以外は main 側を残す）、試験を回してから上げる。版の番号も main のほうが進んでいることがあるので、次の版は両方より大きい番号にする。
- コミットの文は日本語で、何をどう変えたかを書き、末尾に版（例：`（v1.95.0）`）。版は `<div class="ver" aria-hidden="true">vX.Y.Z</div>` も合わせて上げる。
- きまりを変えたら、あそびかた（`#a2RulesOv`）・チュートリアル（`TUTS`）・設計メモ・この引継書も合わせて直す。
- 依頼主が気にしていること：
  - シンプルなルールと奥深い戦略。一つの札に頼りきる形を嫌う（札ごとに役目を分ける）。
  - 世界観の遵守（元素・段階・調律師・坩堝・混沌・無垢・音叉・残響）。言葉の使い分けに気を配る：**闇**は札（闇〈沈降〉）、**混沌**は顕現（敵）の力。〈染〉は「混沌が染みこみ、混沌に染まった」と言い、色も混沌の紅（闇の紫ではない）。
  - 「順序と意味が分かる」演出。ゲーム中の説明は「誰の・いつ・何に・どう」がわかるように。
  - 驚きを残す（音叉の効果をチュートリアルで先に明かさない）。
  - 理想の手応え：第一幕はきまりを知っていれば勝てる／第二幕は連鎖などの工夫で勝てる／第三幕は盤面を読まないと勝てない。
  - 絵は依頼主が生成して渡すこともある（天秤の Lv.1〜3。Lv.4〈真理の天秤〉の絵はもらっているが、いまは使っていない）。
