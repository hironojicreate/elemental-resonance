## 2. 遊びの全体像（いまのきまり）

正本は、ゲームの「あそびかた」（`#a2RulesOv`）と設計メモ。ここでは要点だけ。

**戦闘**
- 坩堝は5列×5段。札を使うと、その元素の欠片が選んだ列に落ちて積もる。1手番に3枚（手数）。
- 落ちた・動いた・変わった欠片は、触れている欠片と反応する（下・左・右・上の順）。
  - 同じ元素・同じ段階は**合成**（一段上へ）。低いほうに残り、横どうしなら動いた側へ相手を引き寄せる。
  - 反対の元素（火⇔水・風⇔土）・同じ段階は**対消滅**。調律の光が顕現を打つ（雫3・輝石8・光核20・真理50）。
- 消えた跡に上が落ちて**連鎖**する。k回目の反応は×k。
- 札で落とした欠片だけは、反応できる相手が2つ以上あれば**相手を選べる**（列の数字に「⇆」）。
- 合成するたびに**〈溜め〉**が貯まる（できた段階ぶん。坩堝の中の合成だけ）。次の対消滅の基本の調律力に足され、連鎖の倍率もかかって使い切られる。
- 坩堝はあなたの楽器：合成はいつもあなたのもの、対消滅はいつも顕現を打つ。

**混沌（敵）**
- 顕現は予告どおりに混沌を降らせる。**反応しない列を選んで**降る（逃げ場がなければ反応する）。
- 敵の番のはじめに、残った混沌が段階の数だけ器を**蝕む**。列からあふれても器が削れる。
- 予告には、撃（器を直接削る）と染（いちばん大きな自分の欠片を混沌にする）もある。

**札の種類**
- **元素の札**（雫・輝石・光核）。**札は光核まで**。真理は坩堝の中でだけ生まれる（光核どうしの合成か、光核に光）。
- **光〈昇華〉**は段階を+1（無垢なら浄化）、**闇〈沈降〉**は段階を−1（**雫なら消えて上が落ちる**）。**光・闇で変えた欠片はあなたの欠片になる**（混沌に使えば「調律した」）。
- **無垢の札**（雫だけ・1拍）：列を押すと〈足場〉（中身のない殻）を置く。手数は使わず、1手番に1枚。周り8マスの対消滅の衝撃で割れ、上の欠片が落ちる。顕現の無垢も同じ中身のない殻（1拍）。〈包む〉と無垢の輝石は v1.95.0 でなくした（エンジンには殻の欠片を解く作りが残っている）。
- **天秤〈入れ替え〉**（札は一種類・**第二幕から**並ぶ。第二幕のはじめの報酬で必ず出会う）：坩堝の2つの欠片の場所を入れ替える（手数1）。1つめを押すと相手が数字つきで光る。届く範囲は音叉で育つ：始まり＝隣どうし／〈兆しの音叉〉で同じ行・列／〈変革の音叉〉でどこでも（絵・名前も変わる）。
- **〈残す〉**：手札のすぐ左の置き場。置いた札は次の手番に持ち越す（音叉で最大3枚）。札は**ドラッグ**でも動かせる（〈残す〉へ・手札へ・坩堝の列や光る欠片へ）。

**真理**
- 坩堝にある自分の真理の数だけ力が重なる（上限なし）：烈火 +0.5倍/つ・慈雨 器+3/つ・疾風 手札+1/つ・不動 手数+1/つ。
- **真理解放**（真理どうしの対消滅）で、**次の敵の番の予告を封じる**（降らない・撃たない・染めない。蝕みは起きる。予告に「封」）。

**音叉と台座**
- 音叉にはコスト（1〜3）があり、**台座**（第一幕3・第二幕6・第三幕9）に収まるぶんだけ付けられる。付けた音叉だけが鳴る。入らない音叉は鞄へ。
- 音叉を持っていれば、戦闘に入る前に**戦いの前の画面**（`R.phase = 'prep'`）が出る。顕現の乱れ・降らせ方・降らせる元素・仕掛けが少しわかり、音叉を付け外しできる。混沌そのものは「？？？」。
- 育つ音叉（掌→双掌・兆し→変革・余韻→長き余韻）は、前の段を同じ台座で上書きする。
- 第一幕の主で〈掌の音叉〉、第二幕の主で〈双掌の音叉〉を必ず授かる（手札の中で錬成・昇華・反転。手数を使わない・光核まで・その戦闘だけ）。

**旅**
- 三幕、分かれ道の地図。戦・鋭（精鋭）・泉（休む／錬成（光核まで）／手放す）・市・謎（出来事6種）・主（幕の主）。
- 敵は21体（各幕：戦4・精鋭2・主1）＋練習の影。
- 主の報酬の札は一段上。第一幕の精鋭の報酬の元素の札は輝石。

### 坩堝のきまり `A2E`
画面に触れない純粋な関数。予告・予測・本番で同じ計算を使う。

| 関数 | 役目 |
|---|---|
| `rk(a, b)` | 2つの欠片の反応（merge / anni / null） |
| `resolve(S, actives, X)` | 反応を解いて連鎖させる |
| `drop(S, c, f, X, hint)` | 列に落とす（`hint` は選んだ相手のます目） |
| `apply(S, id, kind, X)` | 光〈昇華〉・闇〈沈降〉（変えた欠片はあなたのものに。雫の沈降は消える）・（使っていない）無垢〈包む〉 |
| `swap(S, a, b, t, X)` / `swapPartners` / `swapReach` / `canSwapAny` | 天秤の入れ替え（t は段階：1 隣・2 行列・3 どこでも） |
| `partners(S, c, f, H)` | 落ちる先で反応できる相手 |
| `chooseCol(...)` | 混沌の狙い（性格：bury / tall / even / heavy） |
| `enemyTurn(S, intent, X)` | 敵の番（蝕み → 降らす・撃・染）。封じた番は `intent = []` |

- `X`（場の決まりごと）は `A2` の `ctx()` が作る。`calc`（調律力。音叉・真理・〈溜め〉）、`H`、`ward`、`chargeX`、`frames`。
- `frames` に場面を記録すると、`play()` がそれを順に見せる（land / merging / merge / anni / shock / fall / wake / over / bite / strike / taint / raise / flip / weigh / swap など）。

## 5. 検証のしかた

- 道具は `tools/alchemy2/`（使い方は `tools/alchemy2/README.md`）。どれも `index.html` から、きまりと敵の表をその場で読む。
- **きまりを変えたら**：`test/tutorial.js`（筋書きの数字）と、ほかの試験をひととおり（どれも最後に `no errors`）。強さに関わるなら `sim.js` か `sim-skill.js`（腕前・台座ごと）で比べる。
- 戦闘の途中の場面を試すときは、`localStorage` の `genso.a2.run` に状態を書き込んでから「続きから」。**音叉は `relics` と `equip` の両方に入れる**（付けた音叉だけが鳴る）。音叉を持っていると、地図から戦闘へは戦いの前の画面（`#a2Fight`）を通る。
- チュートリアルは数字（乱れの減り方）を説明の文に書いている。きまりを変えたら `tutorial.js` の出力を見て、`TUTS.main` の文と練習の影の体力（`FOES.renshu`、57）を合わせる。

## 7. 残っていること・確かめていないこと

**調整の候補（依頼主と相談中）**
- 〈真理の灯〉〈火水〉は台座1にしては強め（様子を見ている）。
- 第一幕は音叉が入ると易しい（台座3でも、きまりを知っているだけの打ち方で主まで全勝）。
- 第三幕の主（混沌そのもの）の体力は、試遊の手応えを聞いてから。

**ボットで確かめられないもの**
- ボットは1手番先しか読まないので、手番をまたぐ仕込み（殻・足場・〈残す〉・〈溜め〉・天秤）の強さは数字に出にくい。双掌・迎えの鏡・殻・深い坩堝は、ボットでは差が出ない。
- 先見の眼・書の栞・余韻は、ボットが使わない。

**ルール・演出**
- 指でドラッグした直後（0.3秒以内）のタップが、自動の試験ではときどき効かない（ふつうのタップとドラッグは毎回通る）。実機で気になるか見る。
- 天秤のチュートリアル（練習）は隣どうしだけ。兆し・変革の使い方は教えていない（驚きのため）。
- 〈足場〉の強さは、ボットではほとんど測れない（1手番しか読まないので使わない）。人の試遊で見る。
- 闇〈沈降〉で自分の雫を消して上を落とす手は、強すぎないか（ボットでは闇の手の傷は全体の5〜10%）。

**音叉の案**
- 〈導き〉（手番に1度、予告の混沌1つの降る列を決められる）は、案として話しただけ。

## 8. 作業の進め方（これまでの約束）

- 依頼主とのやりとりは日本語。「〜でしょうか」と意見を求められたら、まず意見を出す。数字で決めたいときは「ボットで比べてから」。
- **main へ上げるのは、依頼主が「メインに上げてください」と言ったときだけ**。それまでは作業ブランチにプッシュして、上げるかどうかを尋ねる。main が先に進んでいなければ、早送りで上げる。
- コミットの文は日本語で、何をどう変えたかを書き、末尾に版（例：`（v1.93.0）`）。版は `<div class="ver" aria-hidden="true">vX.Y.Z</div>` も合わせて上げる。
- きまりを変えたら、あそびかた（`#a2RulesOv`）・チュートリアル・設計メモも合わせて直す。
- 依頼主が気にしていること：
  - シンプルなルールと奥深い戦略
  - 世界観の遵守（元素・段階・調律師・坩堝・混沌・無垢・音叉・残響）
  - 「順序と意味が分かる」演出、ゲーム中の説明は「誰の・いつ・何に・どう」がわかるように
  - 驚きを残す（音叉の効果をチュートリアルで先に明かさない）
  - 理想の手応え：第一幕はきまりを知っていれば勝てる／第二幕は連鎖などの工夫で勝てる／第三幕は盤面を読まないと勝てない
