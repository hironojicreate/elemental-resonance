## 2. 遊びの全体像（いまのきまり）

正本は、ゲームの「あそびかた」（`#a2RulesOv`）と設計メモ。ここでは要点だけ。

**戦闘**
- 坩堝は5列×5段。札を使うと、その元素の欠片が選んだ列に落ちて積もる。1手番に3枚（手数）。
- 落ちた・動いた・変わった欠片は、触れている欠片と反応する（下・左・右・上の順）。
  - 同じ元素・同じ段階は**合成**（一段上へ）。低いほうに残り、横どうしなら**動いた側へ相手を引き寄せる**。
  - 反対の元素（火⇔水・風⇔土）・同じ段階は**対消滅**。調律の光が顕現を打つ（雫3・輝石8・光核20・真理50）。
- 消えた跡に上が落ちて**連鎖**する。k回目の反応は×k。
- 札で落とした欠片だけは、反応できる相手が2つ以上あれば**相手を選べる**（列の数字に「⇆」）。
- 合成するたびに**〈溜め〉**が貯まる（できた段階ぶん）。次の対消滅の基本の調律力に足され、連鎖の倍率もかかって使い切られる。手番をまたいで残る。
- 坩堝はあなたの楽器：合成はいつもあなたのもの、対消滅はいつも顕現を打つ。

**混沌（敵）**
- 顕現は予告どおりに混沌を降らせる。**反応しない列を選んで**降る（逃げ場がなければ反応する）。
- 敵の番のはじめに、残った混沌が段階の数だけ器を**蝕む**。列からあふれても器が削れる。
- 予告には、撃（器を直接削る）と染（いちばん大きな自分の欠片を混沌にする）もある。

**札の種類**
- 光〈昇華〉は段階を+1、闇〈反転〉は反対の元素にする。
- 無垢の札（雫＝1拍・輝石＝2拍）：欠片を押せば〈包む〉、列を押せば〈足場〉。手数は使わず、合わせて1手番に1枚。
  - 殻と足場は、周り8マスで対消滅が起きた衝撃で、拍の数だけ耐えて割れる。
  - 顕現の無垢は「中身のない殻（1拍）」。
- 手札の段の左はしの〈残す〉に1枚置くと、次の手番に持ち越せる（音叉で最大3枚）。

**真理の力**
- 坩堝にある自分の真理の数だけ重なる（上限なし）：烈火 +0.5倍/つ・慈雨 器+3/つ・疾風 手札+1/つ・不動 手数+1/つ。

**旅**
- 三幕、分かれ道の地図。戦・鋭（精鋭）・泉（休む／錬成／手放す）・市・謎（出来事6種）・主（幕の主）。
- 敵は21体（各幕：戦4・精鋭2・主1）。
- 音叉は数の制限なしで、23種。うち〈遠見の眼〉は隠しで、抽選に出るのは22種。

### 坩堝のきまり `A2E`
画面に触れない純粋な関数。予告・予測・本番で同じ計算を使う。

| 関数 | 役目 |
|---|---|
| `rk(a, b)` | 2つの欠片の反応（merge / anni / null） |
| `resolve(S, actives, X)` | 反応を解いて連鎖させる |
| `drop(S, c, f, X, hint)` | 列に落とす（`hint` は選んだ相手のます目） |
| `apply(S, id, kind, X)` | 光・闇・無垢〈包む〉 |
| `partners(S, c, f, H)` | 落ちる先で反応できる相手 |

| `enemyTurn(S, intent, X)` | 敵の番（蝕み → 降らす・撃・染） |

- `X`（場の決まりごと）は `A2` の `ctx()` が作る。`calc`（調律力。音叉・真理・〈溜め〉）、`H`、`ward`、`chargeX`、`frames` を持つ。
- `frames` に場面を記録すると、`play()` がそれを順に見せる。記録する場面は land / merging / merge / anni / shock / fall / wake / over / bite / strike / taint など。

## 5. 検証のしかた

- 道具は `tools/alchemy2/`（使い方は `tools/alchemy2/README.md`）。どれも `index.html` から、きまりと敵の表をその場で読む。
- **きまりを変えたら**：`test/tutorial.js`（筋書きの数字が崩れていないか）と、ほかの試験をひととおり。強さに関わるなら `sim.js` で比べる。
- チュートリアルは数字（乱れの減り方）を説明の文に書いている。きまりを変えたら、`tutorial.js` の出力（段ごとの乱れ）を見て、`TUTS.main` の文と練習の影の体力（`FOES.renshu`、いま57）を合わせる。
- 練習の影の予告（`FOES.renshu.pat`）は、盤面を作るために選んである。2つ目の「火1 土1 水1 火1」は、右の火の上に土が乗る形になるよう総当たりで選んだもの。

## 7. 残っていること・確かめていないこと

**強さ**
- 人の難しさは、試遊で見ていく段階。ボットは1手番先しか読まないので、手番をまたぐ仕込み（殻・足場・〈残す〉・〈溜め〉）の強さは数字に出にくい。
- 〈足場〉で混沌の降る場所を誘導できる強さは、ボットで確かめていない。
- 真理の力の重なり（上限なし）は、ボットがあまり真理を作らないので、数字で確かめていない。

**ルール・演出**
- 闇〈反転〉は、その場で反応を起こせない（元素の組は変わらず、同じ組・同じ段階の欠片は隣り合った時点で反応しているため）。殻と組めば生きるが、闇がよく使われるかは未確認。
- チュートリアルで〈足場〉を教えるのは、無垢の練習のまとめの文だけ（操作の段はない）。
- 速い自動試験では、通知（トースト）が少し遅れて重なって見えることがある（人の速さでは目立たない）。

**音叉の案**
- 〈遠見の眼〉（`eyeFoe`、敵の次の次の予告）は、作りを残して抽選から外してある（`hidden: true`）。
- 〈導き〉（手番に1度、予告の混沌1つの降る列を決められる）は、案として話しただけ。強すぎる心配があり、入れるなら幕の主の報酬で、ボットで確かめてから。

**量と扱い**
- 中身の量：敵21体・出来事6種・音叉23種（抽選に出るのは22種）。長く遊ぶには増やしたい。
- もとの錬成の書と試しの対局を残すか、置き換えるかは未定。

## 8. 作業の進め方（これまでの約束）

- 依頼主とのやりとりは日本語。「〜でしょうか」と意見を求められたら、まず意見を出す。数字で決めたいときは「ボットで比べてから」。
- **main へ上げるのは、依頼主が「メインに上げてください」と言ったときだけ**。それまでは `claude/practical-franklin-at5jly` にプッシュして、上げるかどうかを尋ねる。main が先に進んでいなければ、早送りで上げる。
- コミットの文は日本語で、何をどう変えたかを書き、末尾に版（例：`（v1.85.0）`）。版は `<div class="ver" aria-hidden="true">vX.Y.Z</div>` も合わせて上げる。
- きまりを変えたら、あそびかた（`#a2RulesOv`）・チュートリアル・設計メモ（`docs/alchemy2-design.md`）も合わせて直す。
- 依頼主が気にしていること：
  - シンプルなルールと奥深い戦略
  - 世界観の遵守（元素・段階・調律師・坩堝・混沌・無垢・音叉・残響）
  - 「順序と意味が分かる」演出
  - 驚きを残す（音叉の効果をチュートリアルで先に明かさない）
