# サバイバル 設計メモ

サバイバル（降りそそぐ雫に抗うリアルタイムのモード）に足した仕組みと、これから検討する案の記録。

## 天秤ゲージ（v1.96.0）

### ねらい
今は対消滅の相手を選ぶとき、違いが出るのは段階（雫・輝石…）だけで、どの対で消しても同じ。
「どの対で消してきたか」によって「どこまで合成できるか」が決まるようにして、合成と消滅に考える余地を足す。
偏ると作れないという罰だけにせず、偏った側にも得（偏りの稼ぎ）をつけて、**中央を守って真理を育てるか、あえて偏って稼ぐか**を選ばせる。

### 仕様
- 盤の上に横1本。左が火水、右が風土、中央が釣り合った状態。
- 対消滅した石を雫換算で量る（雫1・輝石2・光核4・真理8。2つで1組なので、1回の対消滅で雫2・輝石4・光核8・真理16）。
- 針＝火水の量 − 風土の量。火×水で左（−）、風×土で右（＋）。±16（`BAL_MAX`）で止まる。
  - 累計の割合ではなく差にしたのは、割合だと長く遊ぶほど針が動かなくなるため。端で止めるので、はみ出した分は数えない。
- 合成の上限（`capTier()`）：
  - ±`balTruth`（4）以内 → 真理まで
  - ±`balCore`（10）以内 → 光核まで
  - その外 → 輝石まで
  - 光の〈昇華〉も同じ上限。上限を越える組は `'sealed'` になり、触れても反応しない（クラシックの封印と同じ扱い）。連鎖・衛星・真理解放の合成も同じ。
- 偏りの稼ぎ：針が傾いている側の対消滅は、得点が `1 + (balLean − 1) × |針| / 16`（端で×2）。盤に「偏り ×1.6」と出る。
- **v1.98.0 から、偏りの見返りの基準は重力（〈偏りの重力〉端で半径3.0マス）。得点の上乗せ〈偏りの稼ぎ〉は基準で「なし」（バランス調整で入れられる）。** 爽快感を、数字ではなく目に見える引き寄せで出すため。
- 真理どうしの対消滅は1回で16動くので、中央から撃つと端まで振れる。中央（±4）へ戻すには、反対の対で12（雫6回・輝石3回・光核2回）消す必要がある。撃ったら立て直す、という波が生まれる。
- 見せ方：
  - 帯：中央の明るい帯＝真理、中ほど＝光核、端＝輝石。目盛りは雫2つぶん。中央から針までを、その対の色で塗る。
  - 帯の右に「真理まで／光核まで／輝石まで」、傾いた側に「×1.4」。
  - 合成できない相手に重ねると点線の輪になり、下の文が「天秤が傾いている → 光核は作れない…」、帯が赤く光る。
  - 上限が変わると「天秤が整った／傾いた」と知らせる（真理解放の最中と、2.5秒以内の続けざまは知らせない）。
- 中断・再開で針の位置は残る（律は残らない。コンボも残らないため）。

## 交互の律（v1.96.0）

### ねらい
天秤ゲージの「対を意識させる」ねらいを、罰ではなくその場の手順の工夫として出す。リアルタイムに向く、小さく燃える要素。
天秤の〈偏りの稼ぎ〉（同じ対を続けて稼ぐ）と逆の向きにして、二つの稼ぎ方がぶつかるようにした。

### 仕様
- コンボの間に、火×水と風×土の対消滅を**交互に**起こすと律が1つ上がる。
- 同じ対が続くか、コンボが切れると0。合成・光・闇は律に関わらない（数えも途切れもしない）。
- 律があれば、すべての反応の得点が `1 + rhyStep × 律`（+10%ずつ、上限×2）。チェイン・コンボ・調和の倍率に掛け合わせる。
- 盤に「律 3 ×1.3」、途切れたら（律2以上から）「律が途切れた」。天秤の帯の右端に律の数と倍率。
- 交互に消せば針は中央付近に留まるので、律と真理づくりは相性がよい。偏りの稼ぎとは相性が悪い。

## 切り替え（バランス調整）
どちらも「バランス調整」画面の上のほうで、いつでも切り替えられる（遊んでいる途中に一時停止から変えても、すぐ反映）。

| 項目 | キー | 基準 | 意味 |
|---|---|---|---|
| 天秤ゲージ | `balOn` | あり(1) | なし(0)なら、いつでも真理まで作れて、帯も出ない |
| 真理を作れる中央の幅 | `balTruth` | ±4 | |
| 光核まで作れる幅 | `balCore` | ±10 | 16 にすると輝石止まりの帯がなくなる |
| 偏りの稼ぎ | `balLean` | なし（×1） | 得点の上乗せ。v1.97.0 までは端で×2 |
| 偏りの重力 | `balGrav` | 端で半径3.0 | 1.5 以下で「なし」。v1.97.0 までは「なし」 |
| 交互の律 | `rhyOn` | あり(1) | |
| 律の倍率の伸び | `rhyStep` | +10% | |
| 律の倍率の上限 | `rhyCap` | ×2 | |

天秤も律も「なし」にすると、帯ごと消える。

## 天秤でチェインが伸びる（v1.96.0 の試遊とボットで確認）

依頼主の試遊（律なし・天秤あり）：8分22秒、最大チェイン218、最大コンボ223、得点1,479,059。それまでよりチェインが大きく伸びた。

### ボットで比べた（`node tools/survival/chain-sim.js`、6分×種8つ、律なし）
| | 最大チェイン（平均・中央） | 解放中の最大 | 解放外の最大 | 対消滅 | 盤の欠片 | 得点 |
|---|---|---|---|---|---|---|
| 天秤なし | 56・59 | 56 | 30 | 165 | 19.6 | 31万 |
| 天秤あり | 83・72 | 82 | 38 | 208 | 20.6 | 51万 |
| あり・連鎖の途中は上限を固定 | 80・57（種1つが232） | 80 | 39 | 215 | 19.3 | 53万 |

解放中の長い連鎖（25以上）1本あたり：
- 対消滅（真理を除く）：天秤なし 9.6 → あり 15.6（輝石 1.8→3.4、光核 1.4→2.5）
- 上限の変化：あり 6.6回
- 解放の始まりに盤にある輝石：1.1 → 2.8個

### わかったこと
重力は変えていない（〈偏りの稼ぎ〉は得点だけ）。伸びは主に真理解放の中で起き、理由は三つ。
1. **封が、合成を対消滅に置き換える。** 連鎖は対消滅の重力で周りを引き寄せて広がり、合成では広がらない。上限で合成できない組が引き寄せられても反応せず、代わりに反対の元素と対消滅して、また重力が生まれる。
2. **真理の対消滅で針が大きく振れ、解放の最中に上限が何度も切り替わる。** 下がれば合成が対消滅に置き換わり（1）、上がれば、待っていた組が合成して、その欠片がまた相手を探して飛ぶ。連鎖の途中は上限を固定すると、ふつうの伸び（中央値）はほぼ消える。
3. **合成できずに残った輝石・光核が、解放の火種として盤に貯まる。** 重力の範囲が広い（輝石2.0・光核2.6マス）ので、解放で燃え広がる。

天秤が、ふだんは手を縛り（考える）、真理解放で一気に燃える（見返り）形になっている。ねらってはいなかったが、よい方向の副産物。

### 気をつけること
- 得点が大きく伸びる（ボットで約1.65倍。チェインの倍率と偏りの稼ぎ）。天秤あり・なしのベスト記録が同じ欄に混ざる。
- ボットは盤のどこからでも重ねられて手も速いので、数字は人の試遊より大きく出ることも小さく出ることもある。比べる向きを見るためのもの。

## 中央の無垢の石（v1.97.0）
帯の右の「真理まで／光核まで／輝石まで」の文字は、一瞬では読み取りにくかった。帯を左右の半分に分け、まん中に無垢の石の絵を置いて、いま作れるいちばん上の段階を絵で示す。
- 帯：中央の石から外へ、左が火水・右が風土。内側から真理の帯 → 光核の帯 → 輝石の帯。針と塗りは、傾いている側の半分にだけ出る（釣り合っていれば、石そのものが針の位置）。
- 石：輝石（暗め・点線の縁）・光核（白い縁）・真理（金の縁と光）。段階が変わると弾む。
- 絵は依頼主の無垢の画像（雫・輝石・光核・真理）から、輝石・光核・真理を、形の見える範囲で切り抜き、白い円に収めて濃さを上げたもの（64px の JPEG、CSS の `.bal-st`）。盤で使っている無垢の絵（`pure-1`〜`4`）は淡く、小さくすると形が見えないため、別に持つ。

## 偏りの重力（v1.97.0・バランス調整で入れる。基準は「なし」）
依頼主の案：偏った側の反応を続けると、雫でも広い範囲から引き寄せる重力を持つ（真理には及ばない）。
- `balGrav`：端で届く半径（マス）。v1.98.0 から基準は3.0（v1.97.0 は0＝なし）。3.0 にすると、端では雫（1.5）も輝石（2.0）も光核（2.6）も半径3.0まで届く。真理（3.2・盤全体まで）には及ばない。真理の対消滅は対象外。
- 針が傾いている側の対消滅だけ。広がる量は傾きに比例（半分の傾きで半分）。引き寄せる距離も同じ割合で伸びる。外側の帯（遠いほど弱い重力）も同じだけ外へ。
- 量は針を動かす前の傾きで決める。ドラッグ中の点線の円・下の文（「偏りの重力：半径 2.6 マス…」）・ひらめきも同じ値で見積もる。広がったときは対消滅の地点に、その対の色の輪が出る。

### ボットで比べた（6分×種8つ、律なし。`chain-sim.js` に、傾けて稼ぐボットを足した）
| | 最大チェイン | 解放の外の最大 | 盤の欠片 | 段の平均 | 混沌の最大 | 得点 |
|---|---|---|---|---|---|---|
| 天秤なし | 56 | 30 | 19.6 | 3.09 | 86% | 31万 |
| 中央を守る・重力なし | 83 | 38 | 20.6 | 3.21 | 82% | 51万 |
| 中央を守る・重力3.0 | 79 | 54 | 18.8 | 3.18 | 77% | 53万 |
| 傾けて稼ぐ・重力なし | 118 | 114 | 29.6 | 4.07 | 96% | 174万 |
| 傾けて稼ぐ・重力3.0 | 124 | 98 | 23.9 | 3.96 | 87% | 152万 |

- 傾けて稼ぐ打ち方は、重力がなくても、それだけでチェインと得点が大きく伸びる（端では輝石止まりなので、合成の代わりに対消滅が続き、連鎖が広がる）。代わりに真理が作れず、段は高く、盤は混み、混沌が満ちる寸前まで行く。**稼ぐほど危ない**、という釣り合いになっている。
- 偏りの重力を入れると、傾けた打ち方の盤が片付き（29.6→23.9個）、危なさが減る（混沌の最大 96%→87%）。チェインはほとんど変わらない。中央を守る打ち方には、ほとんど効かない。
- つまり偏りの重力は、「稼ぐほど危ない」の危なさのほうを減らす。傾けた打ち方の得と、中央の打ち方の得（真理で段を戻す）の釣り合いが、傾けた側へ寄る。
- 入れるなら、偏りの稼ぎ（得点）を ×2 → ×1.5 に下げるなどして釣り合いを取るか、稼ぎを得点ではなく重力にする（偏りの稼ぎは重力だけ）、のどちらかを試したい。

### 見返りを重力にするか・中央の真理の意味（依頼主との検討）
依頼主の見立て：まず起爆に真理が要る。中央で真理を複数作っておけば解放が起きやすい。そのあと傾けて、小さな石でも反応させてチェインを稼ぐ。ゲージと重力で、そういう打ち方が生まれる。

ボットで比べた（6分×種8つ、律なし。偏りの稼ぎ：得点×2・重力なし ／ 重力3.0・得点なし）：
| | 得点×2・重力なし | 重力3.0・得点なし |
|---|---|---|
| 傾けて稼ぐ：最大チェイン／解放中の最大 | 118／47 | 124／90 |
| 傾けて稼ぐ：盤・混沌の最大・段の平均 | 29.6個・96%・4.07 | 23.9個・87%・3.96 |
| 傾けて稼ぐ：得点 | 174万 | 120万 |
| 中央を守る：得点・段の平均 | 51万・3.21 | 49万・3.18 |

- 得点の上乗せをやめても、傾けた打ち方は中央の約2.4倍の得点になる。チェインとコンボの倍率で、得点は自然についてくる。
- 傾けて稼ぐボットも真理を15個ほど作っていて、重力を入れると、その解放が大きく伸びた（解放中の最大 47→90）。傾けた状態の重力が、解放の連鎖に効く。
- 真理は、ブレーキ（段を戻す）でもある。傾けて稼ぐ打ち方は段が高く（約4）、混沌が満ちやすい。
- 真理の対消滅は1回で針を16動かすので、中央で撃てば、その瞬間に端まで振れる。「撃つ → 傾いた状態で稼ぐ」は、仕組みとして最初から組み込まれている。端では真理を作れないので、真理は撃つ前に作っておく必要がある。盤に残った真理は、傾いているあいだも雫を引き寄せて衛星を貯め、次の解放の準備になる。
- 巡るボット（中央で真理を育てて撃ち、振れた端で稼ぎ、混沌6割で中央へ戻る）は、傾けている時間が全体の1〜29%にとどまった。傾けると混沌がすぐ6割を超えて、戻らざるを得ないため。傾けて稼ぐ時間は、長く続けるものではなく、短い山場になりやすい。

### 決めたこと（v1.98.0）
依頼主の判断で、偏りの見返りを重力（端で半径3.0）にし、得点の上乗せをなくした。保存の版を v9 にして、古い保存の `balLean`・`balGrav` は新しい基準に置き換える（ほかの設定はそのまま）。

## 調整の候補（人の試遊で見たいこと）
- 真理が作りにくくなりすぎないか。真理はサバイバルの命綱（段を戻す・真理解放）なので、天秤ありだと難しくなる方向に働く。
  - きつければ `balTruth` を 4→6 に、または真理の対消滅で動く量を 16→8 に（真理を雫換算でなく別に数える）。
  - 段の必要数（`lvNeed`）を少し増やして、難しさの帳尻を合わせることも考える。
- 降る雫の元素が運なので、盤が火と水ばかりのときは火水で消すしかなく、偏りが「運のせい」に感じないか。
  - 感じるようなら、針が傾いているあいだは、反対の対の雫が少し降りやすくなる、などの助けを検討。
- 偏りの稼ぎ（×2）と律（×2）のどちらが得か。片方ばかり選ばれるなら倍率を合わせる。
- 〈四元の調和〉（盤上の数の偏り）と天秤（消した対の偏り）の二つのバランスが、ややこしくないか。

## 案B：ミッション（お題）― 検討中・未実装

### ねらい
サバイバルは「生き延びる」だけが目標で、手の選び方は「目の前で反応できるものを消す」に寄りがち。
短い目標（お題）を時々出して、**生き延びるための手とお題のための手がぶつかる場面**を作り、考える・燃える瞬間を足す。

### 形の案
- 30〜60秒ごと（または段が上がるたび）に、お題が1つ出る。制限時間つき（例：45秒）。
- 一度に一つだけ。慣れたら「2つのうちから1つ選ぶ」も試す（選ぶこと自体が考える要素になる）。
- 盤の上（天秤の帯の下、またはステータス帯の位置）に札を1枚：お題の文・進み具合（2/3）・残り時間の輪。
- 達成で報酬、失敗は最初は罰なし（まず「お題があると楽しいか」を見る）。

### お題の種類の案（いまある仕組みとのつながり）
| 種類 | 例 | つながる仕組み |
|---|---|---|
| 作る | 風の光核を作る／真理を作る | 合成。天秤ありなら「真理を作る」は中央に戻す必要があり、天秤とからむ |
| 消す | 輝石の対消滅を3回／火×水で3チェイン | 対消滅・チェイン |
| 律 | 律3に届く | 交互の律 |
| 天秤 | 針を風土側の端へ／針を中央に10秒保つ | 天秤ゲージ。「端へ」は偏りの稼ぎを誘い、真理と引き換えになる |
| 盤 | 調和×1.5を5秒保つ／無垢を浄化する／衛星を3つ連れる | 四元の調和・無垢・衛星 |
| 腕前 | 介入を2回 | 介入 |

段が上がるほど、難しいお題（光核・真理・律の高い段）が出やすくする。

### 報酬の案
- 降下の段が1つ戻る（いちばん効く。真理以外の段の戻し方になる）
- ひらめき +1
- 降下の静止（数秒）
- 得点ボーナス
- 天秤の針を中央へ戻す（天秤ありのとき、偏って稼いだあとの立て直しを助ける）

### 決めたいこと
- 出る間隔と制限時間。リアルタイムなので、札を読む余裕を残す（出た直後は数秒だけ降下を止める、なども）。
- 失敗に罰をつけるか（例：降下が一時的に速まる）。つけると緊張は増えるが、窮屈にもなる。
- 選ばせるか、決めて出すか。
- サバイバルの中に入れるか、別のモード（「ミッション」）にするか。結果画面に「達成したお題の数」を出すか。
- 天秤・律と同じく、バランス調整で「なし」にできるようにする。

### 実装の手がかり
- お題の進み具合は、いまある処理に数えを足せば取れる：`doMerge`（できた段階・元素）、`doAnni`（段階・元素・チェイン）、`registerReaction`（介入）、`rhyNote`（律）、`balShift`（針）、`attachSat`（衛星）、浄化の処理、`harmonyMult()`（調和）。
- 時間の進みは `tick()`（サバイバルの毎フレーム）に。
- 札の見た目は、天秤の帯（`.bal`）と同じ枠の作りで足せる。
