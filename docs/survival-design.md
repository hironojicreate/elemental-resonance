# サバイバル 設計メモ

サバイバル（降りそそぐ雫に抗うリアルタイムのモード）に足した仕組みと、これから検討する案の記録。

## 天秤ゲージ（v1.96.0）

### ねらい
今は対消滅の相手を選ぶとき、違いが出るのは段階（雫・輝石…）だけで、どの対で消しても同じ。
「どの対で消してきたか」によって「どこまで合成できるか」が決まるようにして、合成と消滅に考える余地を足す。
偏ると作れないという罰だけにせず、偏った側にも得（偏りの稼ぎ）をつけて、**中央を守って真理を育てるか、あえて偏って稼ぐか**を選ばせる。

### 仕様
- 盤の上に横1本。左が火水、右が風土、中央が釣り合った状態。
- 対消滅した石を雫換算で量る（雫1・輝石2・光核4・真理8。2つで1組なので、1回の対消滅で雫2・輝石4・光核8・真理16）。
- 針＝火水の量 − 風土の量。火×水で左（−）、風×土で右（＋）。±16（`BAL_MAX`）で止まる。
  - 累計の割合ではなく差にしたのは、割合だと長く遊ぶほど針が動かなくなるため。端で止めるので、はみ出した分は数えない。
- 合成の上限（`capTier()`）：
  - ±`balTruth`（4）以内 → 真理まで
  - ±`balCore`（10）以内 → 光核まで
  - その外 → 輝石まで
  - 光の〈昇華〉も同じ上限。上限を越える組は `'sealed'` になり、触れても反応しない（クラシックの封印と同じ扱い）。連鎖・衛星・真理解放の合成も同じ。
- 偏りの稼ぎ：針が傾いている側の対消滅は、得点が `1 + (balLean − 1) × |針| / 16`（端で×2）。盤に「偏り ×1.6」と出る。
- 真理どうしの対消滅は1回で16動くので、中央から撃つと端まで振れる。中央（±4）へ戻すには、反対の対で12（雫6回・輝石3回・光核2回）消す必要がある。撃ったら立て直す、という波が生まれる。
- 見せ方：
  - 帯：中央の明るい帯＝真理、中ほど＝光核、端＝輝石。目盛りは雫2つぶん。中央から針までを、その対の色で塗る。
  - 帯の右に「真理まで／光核まで／輝石まで」、傾いた側に「×1.4」。
  - 合成できない相手に重ねると点線の輪になり、下の文が「天秤が傾いている → 光核は作れない…」、帯が赤く光る。
  - 上限が変わると「天秤が整った／傾いた」と知らせる（真理解放の最中と、2.5秒以内の続けざまは知らせない）。
- 中断・再開で針の位置は残る（律は残らない。コンボも残らないため）。

## 交互の律（v1.96.0）

### ねらい
天秤ゲージの「対を意識させる」ねらいを、罰ではなくその場の手順の工夫として出す。リアルタイムに向く、小さく燃える要素。
天秤の〈偏りの稼ぎ〉（同じ対を続けて稼ぐ）と逆の向きにして、二つの稼ぎ方がぶつかるようにした。

### 仕様
- コンボの間に、火×水と風×土の対消滅を**交互に**起こすと律が1つ上がる。
- 同じ対が続くか、コンボが切れると0。合成・光・闇は律に関わらない（数えも途切れもしない）。
- 律があれば、すべての反応の得点が `1 + rhyStep × 律`（+10%ずつ、上限×2）。チェイン・コンボ・調和の倍率に掛け合わせる。
- 盤に「律 3 ×1.3」、途切れたら（律2以上から）「律が途切れた」。天秤の帯の右端に律の数と倍率。
- 交互に消せば針は中央付近に留まるので、律と真理づくりは相性がよい。偏りの稼ぎとは相性が悪い。

## 切り替え（バランス調整）
どちらも「バランス調整」画面の上のほうで、いつでも切り替えられる（遊んでいる途中に一時停止から変えても、すぐ反映）。

| 項目 | キー | 基準 | 意味 |
|---|---|---|---|
| 天秤ゲージ | `balOn` | あり(1) | なし(0)なら、いつでも真理まで作れて、帯も出ない |
| 真理を作れる中央の幅 | `balTruth` | ±4 | |
| 光核まで作れる幅 | `balCore` | ±10 | 16 にすると輝石止まりの帯がなくなる |
| 偏りの稼ぎ | `balLean` | 端で×2 | 1 にすると稼ぎなし（罰だけの天秤） |
| 交互の律 | `rhyOn` | あり(1) | |
| 律の倍率の伸び | `rhyStep` | +10% | |
| 律の倍率の上限 | `rhyCap` | ×2 | |

天秤も律も「なし」にすると、帯ごと消える。

## 確かめたこと
- `node tools/survival/balance.js`：針の動き、上限（中央・中ほど・端）、偏りの稼ぎ（端の雫の対消滅が 40×2×調和）、律、切り替え、封の理由の文、中断と再開。すべて通る。
- 簡単なボットで30秒遊ばせて、エラーなし。針は −4〜+8 の間を動き、律は2まで上がった。

## 調整の候補（人の試遊で見たいこと）
- 真理が作りにくくなりすぎないか。真理はサバイバルの命綱（段を戻す・真理解放）なので、天秤ありだと難しくなる方向に働く。
  - きつければ `balTruth` を 4→6 に、または真理の対消滅で動く量を 16→8 に（真理を雫換算でなく別に数える）。
  - 段の必要数（`lvNeed`）を少し増やして、難しさの帳尻を合わせることも考える。
- 降る雫の元素が運なので、盤が火と水ばかりのときは火水で消すしかなく、偏りが「運のせい」に感じないか。
  - 感じるようなら、針が傾いているあいだは、反対の対の雫が少し降りやすくなる、などの助けを検討。
- 偏りの稼ぎ（×2）と律（×2）のどちらが得か。片方ばかり選ばれるなら倍率を合わせる。
- 〈四元の調和〉（盤上の数の偏り）と天秤（消した対の偏り）の二つのバランスが、ややこしくないか。

## 案B：ミッション（お題）― 検討中・未実装

### ねらい
サバイバルは「生き延びる」だけが目標で、手の選び方は「目の前で反応できるものを消す」に寄りがち。
短い目標（お題）を時々出して、**生き延びるための手とお題のための手がぶつかる場面**を作り、考える・燃える瞬間を足す。

### 形の案
- 30〜60秒ごと（または段が上がるたび）に、お題が1つ出る。制限時間つき（例：45秒）。
- 一度に一つだけ。慣れたら「2つのうちから1つ選ぶ」も試す（選ぶこと自体が考える要素になる）。
- 盤の上（天秤の帯の下、またはステータス帯の位置）に札を1枚：お題の文・進み具合（2/3）・残り時間の輪。
- 達成で報酬、失敗は最初は罰なし（まず「お題があると楽しいか」を見る）。

### お題の種類の案（いまある仕組みとのつながり）
| 種類 | 例 | つながる仕組み |
|---|---|---|
| 作る | 風の光核を作る／真理を作る | 合成。天秤ありなら「真理を作る」は中央に戻す必要があり、天秤とからむ |
| 消す | 輝石の対消滅を3回／火×水で3チェイン | 対消滅・チェイン |
| 律 | 律3に届く | 交互の律 |
| 天秤 | 針を風土側の端へ／針を中央に10秒保つ | 天秤ゲージ。「端へ」は偏りの稼ぎを誘い、真理と引き換えになる |
| 盤 | 調和×1.5を5秒保つ／無垢を浄化する／衛星を3つ連れる | 四元の調和・無垢・衛星 |
| 腕前 | 介入を2回 | 介入 |

段が上がるほど、難しいお題（光核・真理・律の高い段）が出やすくする。

### 報酬の案
- 降下の段が1つ戻る（いちばん効く。真理以外の段の戻し方になる）
- ひらめき +1
- 降下の静止（数秒）
- 得点ボーナス
- 天秤の針を中央へ戻す（天秤ありのとき、偏って稼いだあとの立て直しを助ける）

### 決めたいこと
- 出る間隔と制限時間。リアルタイムなので、札を読む余裕を残す（出た直後は数秒だけ降下を止める、なども）。
- 失敗に罰をつけるか（例：降下が一時的に速まる）。つけると緊張は増えるが、窮屈にもなる。
- 選ばせるか、決めて出すか。
- サバイバルの中に入れるか、別のモード（「ミッション」）にするか。結果画面に「達成したお題の数」を出すか。
- 天秤・律と同じく、バランス調整で「なし」にできるようにする。

### 実装の手がかり
- お題の進み具合は、いまある処理に数えを足せば取れる：`doMerge`（できた段階・元素）、`doAnni`（段階・元素・チェイン）、`registerReaction`（介入）、`rhyNote`（律）、`balShift`（針）、`attachSat`（衛星）、浄化の処理、`harmonyMult()`（調和）。
- 時間の進みは `tick()`（サバイバルの毎フレーム）に。
- 札の見た目は、天秤の帯（`.bal`）と同じ枠の作りで足せる。
