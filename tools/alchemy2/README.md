# 錬成の書２の検証の道具

`index.html` の中の坩堝のきまり（`A2E`）と顕現の表（`FOES`）を、その場で読み出して使う。ゲームを直せば、道具もそのまま新しい数字で動く。Node と、Playwright（`require('playwright')` が動く環境）が要る。

## シミュレーション（強さの調整）

```bash
node tools/alchemy2/sim.js
```

1手番先まで札の組み合わせを全部読むボットで、顕現ごとに戦わせる。ゲームと同じく、反応させる相手を選び、〈溜め〉を使う。

| 環境変数 | 意味 |
|---|---|
| `K` | 敵の名前（カンマ区切り。例 `K=hiyura,arashi`）。省くと全21体 |
| `N` | 1体あたりの戦数（既定 12） |
| `HPS` | 敵の体力の倍率（例 `HPS=1.2`） |
| `SH` | 山札の雫を、無垢の雫に替える枚数 |
| `DARK1=1` | 第一幕の山札に闇を1枚 |
| `CHOICE=0` | 相手を選ばない（いつもの順だけ） |
| `SEED` | 乱数の種 |

山札は幕ごとの典型（`DECKS`）、器は60で測る。人はこのボットの1.5〜2倍は削られる見込み。〈溜め〉や相手を選ぶ操作を、毎回いちばん良く使えるのはボットだけなので、調整では人との差を見込む（v1.84.0 の経緯を参照）。

## 画面の試験（Playwright）

```bash
node tools/alchemy2/test/tutorial.js
```

どれも最後に `no errors`（ページの例外がない）を出す。スクリーンショットは環境変数 `OUT` のフォルダへ（既定は一時フォルダ）。

| ファイル | 確かめること |
|---|---|
| `tutorial.js` | はじめのチュートリアル（27段）を最後まで。段ごとの乱れ・器・予報。`SHOTS=0` で撮らない |
| `shell-practice.js` | 報酬にはじめて無垢が並ぶ → 無垢の練習 → 報酬に戻る |
| `shell-break.js` | 殻が割れる演出の順番（ふつうの速さ） |
| `modes.js` | ほかのモードが開けるか、保存・続きから |
| `full-run.js` | 器600の写しで三幕を最後まで（単純なボット） |
| `keep.js` / `keep3.js` | 〈残す〉（1枚・〈長き余韻〉で3枚） |
| `shell.js` / `scaffold.js` | 無垢〈包む〉・〈足場〉 |
| `partner.js` | 反応させる相手を選ぶ |
| `truth.js` | 真理の力の重なり |
| `eye.js` | 〈先見の眼〉〈書の栞〉 |
| `hurt.js` | 器への傷の演出（撮るだけ） |

戦闘の途中の場面を試すときは、`localStorage` の `genso.a2.run` に冒険の状態を書き込んでから「続きから」を押す（`partner.js` などを参照）。
